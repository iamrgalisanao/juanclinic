# AI Governance & SDLC Ledger

This directory serves as the evidence hub for JuanClinic HIS development. It tracks requirements, assumptions, and validation proof to ensure adherence to clinical standards and multi-tenant isolation rules.

## Primary Documents

- **normalized-requirements.md**: The source of truth for task objectives and scope.
- **assumptions-register.md**: Tracking technical and domain assumptions to be validated.
- **validation-reports.md**: Evidence of functional and clinical verification.
- **task-ledger.md**: High-level tracking of active and completed development milestones.
- **open-questions.md**: Unresolved points requiring user or stakeholder clarification.

## Usage Rule
All High/Critical risk tasks MUST update the relevant documents in this directory before implementation (Stages 1-3) and before release (Stages 6-9) as defined in the `Operational_protocol.md`.
